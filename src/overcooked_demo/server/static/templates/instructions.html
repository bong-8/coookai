이 실험에서 여러분은 수프 가게의 요리사 두 명 중 한 명이 되어 파트너와 함께 수프를 만들어 서빙합니다. 파트너는 AI 봇이거나 다른 참가자입니다. 난이도(주방 배치)는 총 5단계이며 순서대로 진행되고, 각 단계는 60초씩입니다. (각 단계가 끝나면 잠시 뒤 다음 단계가 자동으로 시작됩니다.)

이동과 상호작용

방향키(← ↑ → ↓)로 이동하고 스페이스바로 상호작용합니다. 상호작용은 사물을 바라보고(그쪽으로 방향키를 누른 상태) 스페이스바를 누르는 방식입니다.

  • 빈 손으로 재료 보급대(양파/토마토)를 보고 스페이스바 → 재료를 집습니다.
  • 재료를 든 채 빈 카운터를 보고 스페이스바 → 카운터에 내려놓습니다. (카운터의 물건도 같은 방식으로 다시 집을 수 있습니다.)
  • 재료를 든 채 가득 차지 않은 냄비를 보고 스페이스바 → 냄비에 넣습니다. 냄비에는 최대 3개까지 들어갑니다.
  • 빈 손으로 재료가 들어 있는 냄비를 보고 스페이스바 → 요리를 시작합니다. (3개가 다 차면 자동으로 시작되기도 합니다.)
  • 접시를 들고 완성된 수프가 담긴 냄비를 보고 스페이스바 → 수프를 접시에 담습니다.
  • 수프가 담긴 접시를 든 채 서빙대(회색 칸)를 보고 스페이스바 → 서빙(제출)합니다.

두 요리사는 같은 칸에 동시에 있을 수 없습니다. 서로 길을 막지 않게 주의하세요.

요리

요리를 시작하면 냄비 위에 빨간 숫자가 나타나 조리 시간을 보여 줍니다(완성될 때까지 올라갑니다). 조리 시간은 재료로 정해집니다: 양파 1개당 {{ layout_conf.onion_time }}, 토마토 1개당 {{ layout_conf.tomato_time }}씩 더해집니다. (숫자 단위는 게임 내부 틱입니다.)

수프의 기본 점수도 재료로 정해집니다: 양파 1개당 {{ layout_conf.onion_value }}점, 토마토 1개당 {{ layout_conf.tomato_value }}점. 예) 양파 3개 수프 = {{ layout_conf.onion_value * 3 }}점.

주문 목록과 점수

게임 화면 아래 정보 패널의 "주문 목록"에 지금 들어와 있는 주문이 아이콘으로 표시됩니다. 주문 목록에 있는 수프를 서빙해야만 점수가 됩니다.

  • 시작할 때 주문이 1개 들어와 있습니다.
  • 이후 10초마다 새 주문이 1개씩 추가됩니다. 주문에는 만료(제한 시간)가 없어서, 서빙하기 전까지 목록에 계속 남아 쌓입니다.
  • 목록에 있는 수프를 서빙하면 점수를 얻고 그 주문 1개가 목록에서 사라집니다. 같은 주문이 여러 개 있으면 한 번에 하나씩만 사라집니다.
  • 목록에 없는 수프를 서빙하면 0점이며 수프만 사라집니다. (주문 목록이 비어 있을 때 서빙해도 0점입니다.)
  • 주문 목록의 순서는 난이도마다 항상 같습니다. (참가자마다 주문이 달라지지 않습니다.)

보너스 주문이 있는 난이도(예: 마지막 단계의 양파+토마토 수프)에서는 해당 수프를 주문 목록에 맞춰 서빙할 때 기본 점수의 {{ layout_conf.order_bonus }}배를 받습니다. 보너스 주문은 화면의 "보너스:" 칸에 표시됩니다.

이 실험의 다섯 난이도 중 네 곳은 양파 3개 수프({{ layout_conf.onion_value * 3 }}점)만 주문으로 들어옵니다. 마지막 단계(counter_circuit)는 양파·토마토를 섞은 서로 다른 수프 주문이 들어오므로 목록의 아이콘을 잘 확인하세요.

파트너에게 신호 보내기 (소통 버튼)

게임 화면 아래의 버튼 4개(또는 키보드 1~4)로 파트너에게 간단한 신호를 보낼 수 있습니다. 신호를 보내면 내 캐릭터 머리 위에 말풍선이 잠깐 표시됩니다. 말은 이 4가지로만 할 수 있습니다.

AI 봇은 신호를 받으면 곧바로 "OK" 말풍선으로 확인했다고 알려 주고, 약간의 시간 뒤에 위 표대로 행동합니다.

AI 파트너의 특징

  • AI 봇은 재료를 가져오고, 냄비에 넣고, 요리를 시작하고, 접시를 가져오는 일을 합니다.
  • 기본적으로 완성된 수프를 서빙대에 가져가는 일은 하지 않습니다. (서빙은 여러분의 몫이며, "도와줘" 신호를 받았을 때만 도와줍니다.)
  • 봇은 일부러 천천히 움직입니다(사람 속도의 약 1/3). 봇이 느려 보여도 정상입니다.
  • 봇이 길을 막고 있으면 "비켜줘"를 사용해 보세요.

목표

각 단계의 60초 동안 주문 목록에 있는 수프를 가능한 많이, 빠짐없이 서빙해 점수를 높이는 것이 목표입니다. 남은 시간(Time Left), 점수(Score), 주문 목록은 화면 아래 패널에 표시됩니다. 모든 단계가 끝나면 "게임 기록 보기"에서 단계별 점수와 소통 버튼 사용 횟수를 확인할 수 있습니다.

※ 시작 화면에서 입력한 닉네임과 게임 중의 움직임·소통 버튼 사용 기록은 연구 목적으로 저장됩니다.
